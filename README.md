# PriorAI — AI-Powered Task Manager

A full-stack task management application that uses AI to help you prioritize smarter.

🔗 **Live Demo:** https://priorai-kappa.vercel.app

---

## Features

- 🧠 AI priority scoring based on urgency and importance
- ✨ Automated subtask generation
- 🔍 AI-suggested articles and resources per task
- 🗂️ Kanban board and priority-sorted list view
- 📊 3D analytics dashboard
- 🔐 JWT-based authentication

---

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React.js, Vite, Tailwind CSS |
| Backend | Node.js, Express.js |
| Database | MongoDB, Mongoose |
| AI | Groq API (Llama 3.3-70B) |
| Deployment | Vercel |
